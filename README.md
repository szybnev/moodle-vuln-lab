# moodle-vuln-lab

**TL;DR** — воспроизводимая лаборатория из пяти реальных версий Moodle (3.11 → 5.3)
в Docker с намеренно заложенными ошибками конфигурации и сценариями проверки
с «ключом ответов». Нужна, чтобы честно проверять внешние сканеры Moodle:
определяют ли они точную версию, применимые уязвимости и мисконфигурации, и
не дают ли ложных срабатываний на защищённом экземпляре.

> ⚠️ Экземпляры **намеренно уязвимы**. Все порты привязаны к `127.0.0.1`.
> Не публикуйте их в сеть, не запускайте на общих серверах.

Лаборатория использовалась для валидации
[szybnev/Moodle-Scanner](https://github.com/szybnev/Moodle-Scanner)
(матрица результатов: [docs/validation-matrix.md](https://github.com/szybnev/Moodle-Scanner/blob/main/docs/validation-matrix.md)),
но от сканера не зависит: подходит для любого инструмента.

## Для кого

- авторам сканеров и шаблонов (nuclei и т.п.) — регрессионный стенд;
- пентестерам и SOC — тренировка ручного фингерпринтинга Moodle;
- платформам внешнего тестирования — приёмочные тесты интеграций.

## Экземпляры

| имя | Moodle | PHP | PostgreSQL | порт | особенности |
|---|---|---|---|---|---|
| m311 | v3.11.8 | 7.4 | 13 | 8311 | все мисконфигурации, плагин `mod_customcert` |
| m401 | v4.1.2 (ранний 4.1 LTS) | 8.0 | 16 | 8401 | саморегистрация, debug, открытый `.git` |
| m405 | v4.5.1 (диапазон CVE-2025-32044) | 8.2 | 16 | 8405 | гостевой вход, web services, `config.php.bak`, доступный dataroot, плагины `local_staticpage`, `block_xp` |
| m500 | v5.0.2 | 8.3 | 16 | 8500 | настройки Moodle по умолчанию, плагин `mod_attendance` |
| m503 | v5.3.0 (последний) | 8.4 | 17 | 8503 | **защищённый негативный контроль**, web root `public/` |

Конфигурация — [`instances.json`](instances.json); код Moodle скачивается с точного
git-тега github.com/moodle/moodle, плагины — с закреплённых ref на GitHub;
образы `moodlehq/moodle-php-apache` и `postgres`.

## Сценарии

Ключ ответов — [`scenarios.json`](scenarios.json): для каждого сценария указано,
на каких экземплярах условие присутствует.

| id | что проверяется | где присутствует |
|---|---|---|
| S01 | точная версия без авторизации | все (ответы в `scenarios.json`) |
| S02 | саморегистрация по email | m311, m401 |
| S03 | кнопка гостевого входа | m311, m401, m405, m500 |
| S04 | web services / токен-эндпоинт | m311, m405 |
| S05 | debug со стек-трейсами | m311, m401 |
| S06 | dataroot доступен по HTTP | m311, m405 |
| S07 | открытый `.git` | m311, m401 |
| S08 | резервная копия `config.php` | m311, m405 |
| S09 | composer/dev-файлы | m311, m401, m405, m500 |
| S10 | точная версия в `lib/upgrade.txt` | m311, m401 |
| S11 | сторонние плагины | m311, m405, m500 |
| S12 | доступный веб-инсталлятор | нигде (негатив) |
| S13 | CVE-2025-32044 (MSA-25-0011) применима | m405 (только ключ, без эксплуатации) |
| S14 | защищённый экземпляр без находок | m503 |

Любая находка сканера на m503 по S02–S12 — ложное срабатывание.

## Запуск

Нужны Docker, Python 3.10+ (только stdlib) и доступ к GitHub и Docker Hub.

```sh
python3 lab.py up              # скачать, поднять, установить, засеять (~8 минут первый раз)
python3 lab.py verify          # проверить, что все сценарии живы там, где положено
python3 lab.py down --purge    # удалить контейнеры, тома, сеть и исходники
```

`--only m405 m500` ограничивает `up`/`verify` частью экземпляров. После `up`
фактические настройки, прочитанные из Moodle, лежат в `.work/<имя>/truth.json`.
Администратор: `admin` / `Lab-Admin-Pass-1!` (только для лаборатории).

`verify` делает по одному GET на сценарий и печатает таблицу; `!` отмечает
расхождение с `scenarios.json`, код выхода 1 при любом расхождении.

## Как засеяны ошибки

| засев | способ |
|---|---|
| саморегистрация | `auth=email`, `registerauth=email` через `admin/cli/cfg.php` |
| гостевой вход | `guestloginbutton=1` |
| web services | `enablewebservices=1`, `enablemobilewebservice=1` |
| debug | `debug=32767`, `debugdisplay=1` |
| `.git` | `git init` в web root |
| копия конфига | `config.php` → `config.php.bak` |
| dataroot | симлинк `<webroot>/moodledata` и [`apache/exposed-dataroot.conf`](apache/exposed-dataroot.conf) (`.htaccess` игнорируется, как на nginx) |
| защита m503 | всё выключено + [`apache/hardened.conf`](apache/hardened.conf) по мотивам рекомендаций Moodle |
